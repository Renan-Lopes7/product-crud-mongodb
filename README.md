## ⚙️ Funcionalidades

- Listagem de todos os produtos
- Cadastro de novo produto com imagem
- Visualização de detalhes do produto
- Edição de produto existente
- Exclusão de produto

## 🚀 Como rodar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/) rodando localmente

### Instalação

```bash
# Clone o repositório
git clone https://github.com/Renan-Lopes7/product-crud-mongodb.git

# Acesse a pasta
cd product-crud-mongodb

# Instale as dependências
npm install
```
### Execução

```bash
node index.js
```

Acesse em: [http://localhost:1000/products](http://localhost:1000/products)

## 🛠️ Tecnologias

- **Node.js** — runtime JavaScript
- **Express** — framework web
- **MongoDB** — banco de dados NoSQL
- **MVC** — arquitetura do projeto
- **Nodemon** — reload automático em desenvolvimento
- **Handlebars** — template engine
