Aplicação web para gerenciamento de produtos (CRUD), desenvolvida com Node.js, Express, MongoDB e Handlebars.
Permite criar, visualizar, editar e excluir produtos com preços e categorias, seguindo arquitetura MVC.

### Tecnologias utilizadas
Node.js
Express
MongoDB 
Express Handlebars (template engine)
Arquitetura MVC
Nodemon para desenvolvimento

#### Funcionalidades
Cadastro de produtos com nome e preço.
Edição e exclusão de produtos.
Interface simples com formulários e views renderizadas.
Projeto desenvolvido como parte de um curso de Node.js e MongoDB.
